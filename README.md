## Facciamo un'app - Flutter Projects 📱
This repository contains the projects I built during the **Poli.College "Facciamo un'app (Lets make an app)" course**. Through these projects, I learned the fundamentals of mobile application development using **Flutter** and **Dart**, moving from basic UI layouts to state management and data handling.

## 📂 What’s Inside:
  - Three distinct Flutter applications built as assignments throughout the course.
  - Clean, widget-based UI layouts designed for mobile devices.
  
## 📝 Projects:
  - **Counter App**: 
    The classic first step in Flutter! This project helped me understand the difference between Stateless and Stateful widgets, and how to update the UI dynamically when a user interacts with a button.

  - **Calculator**: 
    A fully functional calculator app. Building this allowed me to practice grid layouts, complex button interactions, and managing the logic behind mathematical operations.

  - **JSON File Project**: 
    A project focused on data handling. To be honest, coming in with zero JavaScript or JSON experience, I wasn't entirely sure what I was doing at first. However, I learned that it's a way to structure data so Flutter can read it, parse it, and display it dynamically in the UI, or something like that.

## 🎨 Technologies and Tools Used:
  - **Dart**: The programming language used to write the logic and structure of the applications.
  - **Flutter**: The UI toolkit used to build natively compiled cross-platform applications from a single codebase.
  - **VS Code / Android Studio**: The IDEs used for writing, debugging, and running the applications on emulators.

## 📝 P.S.:
Switching from languages like Python and HTML/CSS to Dart's widget-tree structure was definitely a challenge at first. Wrapping my head around nesting widgets and managing application state took some getting used to. Whenever I hit a roadblock or got lost in complex layouts, I used a mix of course resources, Flutter documentation, and AI assistance to debug my code. 


I'm really proud of how much I learned about mobile development through these projects, and I can't wait to build more complex apps next!
